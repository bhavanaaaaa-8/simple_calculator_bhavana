# Simple Calculator

A simple Python calculator that performs basic mathematical operations.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Uses separate functions for each operation
- Displays the result clearly

## How to Run

1. Make sure Python is installed.
2. Run the Python file.
3. Enter two numbers.
4. Enter an operator (`+`, `-`, `*`, or `/`).
5. The calculator will display the result.

## Example

```text
Enter first number: 20
Enter operator (+, -, *, /): /
Enter second number: 5

----------------------
      CALCULATOR
----------------------
First Number : 20.0
Operator     : /
Second Number: 5.0
----------------------
Result       : 4.0
----------------------
```

## Requirements

- Python 3.x
